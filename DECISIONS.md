# Decisions

## 2026-07-04

### Name
Use **Ana** as the name of the companion.

### Project structure
- Ana: AI companion
- Project Ana: larger mission-driven initiative
- Ana One: first hardware device
- Ana Solar: future rugged solar-assisted version

### Motto
Use **Ask. Nurture. Aspire.**

### Offline-first
Normal use must not require internet access or cloud inference.

### Privacy
Privacy is a core product requirement, not an optional setting.

### Audio direction
Explore a permanently attached single earbud as the primary audio output. No Bluetooth is required for Version 0.1.

### Solar
Solar charging is not required for Ana One but should be anticipated in the architecture.

## 2026-08-10

### Product hypothesis
The strongest current differentiation is the combination of:
- girls-first design
- personal ownership
- offline operation
- privacy
- agency-building educational behavior

### Discovery before solution
Validate the household device-access problem and educational need before locking the product.

### Danny's role
Danny's primary role is convener: bring together educational expertise, technical talent, design talent, and capital.
